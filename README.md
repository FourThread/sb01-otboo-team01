# 프로젝트 소개
OZANG 프로젝트는 사용자가 등록한 옷을 날씨 기반으로 개인 맞춤형 의상 조합을 추천해주는 플랫폼입니다. <br>
추천된 의상은 OOTD에 등록할 수 있으며, 다른 사용자의 스타일을 팔로우, 좋아요 및 댓글과 DM을 통해 함께 즐길 수 있습니다.
